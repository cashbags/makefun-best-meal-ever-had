One sentence, 155 characters, about the best meal ever had: pecel lele eaten
by hand on a plastic stool in Yogyakarta, sambal stinging, the catfish
crackling so loud the vendor laughed first. Entry for the
[make.fun competition](https://make.fun/competitions/u-pangg7-the-best-meal-you-ever-had-a3ac0f85).

`main.py` writes the sentence to `/output/entry.txt` deterministically — the
same 155 bytes on every run, no network, no input. See `DESIGN.md` for the
tournament that picked it (8 candidates, 28 pairwise games, winner 7–0).

Built with [make.fun](https://make.fun/r/qrg7fvky).
